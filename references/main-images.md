# 指定静态主图采样

普通“读取商品图片集”优先回读已有详情结果；新读取使用独立的[--gallery入口](gallery.md)，结果在 `result.gallery.items`。原 `--details` 的 `details.gallery.items` 继续有效：真实元素URL、顺序、尺寸、加载状态及来源。这个区域当前是缩略图区域，不能改写后缀猜测原图，也不必为取得这些数据逐张切图、识别或关闭营销弹窗。已有完成结果优先回读，保留原观察时间。

`--main-images FILE` 为一个已绑定商品选择1–3张已观察到的静态缩略图，取得当前主图元素的实际URL、自然尺寸、显示尺寸和加载状态。它独立于只读的 `--details`，不关闭评价、展开面板、自动滚动、下载图片或播放视频。

只有调用方明确需要“指定缩略图选中后对应的当前主图”时才使用这个可能切图的模式。其内部只读采集与点击保护分开：未知遮罩不阻止读取已加载主图元素；只有选择动作需要目标可交互且无遮挡。明确的登录、验证码和频控仍暂停。这个调整仅适用于主图采集器，不放宽其他读取模式的页面保护。

## 使用

先使用原状态目录检查 `tabs` 和目标绑定。计划文件是JSON数组，内容为该商品已有 `details.gallery.items[].url` 中需要采样的完整缩略图URL，例如：

```json
["https://img.alicdn.com/imgextra/i4/2211351408444/O1CN01Dg2sDs2CFPW1mQMuG_!!2211351408444.jpg_q50.jpg_.webp"]
```

该例来自手机1069125756045的历史观察，仅说明文件格式，不授权重放已经完成的研究批次。实际使用须指定当前请求范围与正确商品，保留其原预算。文件最多8 KiB，不接受符号链接、重复项、非支持CDN或带查询参数的地址；不能修改后缀来猜主图URL。每次读取和选图都重新核对商品地址及页面中精确匹配的缩略图。

```sh
node scripts/shopping.mjs task-start --task <新请求任务名> --bindings <商品绑定名> --main-images <计划JSON路径> --state-dir <原状态目录>
node scripts/shopping.mjs task-run --task <原任务名> --state-dir <原状态目录>
node scripts/shopping.mjs task-status --task <原任务名> --state-dir <原状态目录>
```

开发继续使用 `.runtime/verification-bindings`。本模式最多一个绑定，与规格计划、搜索、详情、服务及评价模式互斥。已有失败任务不得改名或换目录获得新预算。完成后再执行只回读缓存，不刷新图片。

## 确认与预算

- 每张最多4次主图观察、1次选图意图；一批最多12次观察、3次意图，失败读取同样计数。动作和读取均先落盘，相邻观察及动作后的观察至少间隔1.5秒。
- 新任务使用主图子格式2。初次已选中时不点击；需要选中标记、已加载的主图，以及连续两次URL、尺寸、加载状态一致。`uncovered` 作为观察信息保留，不要求为true，也不因两次遮挡状态不同打断数据确认。
- 初次未选中时，只点击唯一、可见且中心无遮挡的普通静态缩略图一次。后读还必须看到主图URL相对初次观察改变，才可用两次一致结果确认；只换了选中标记不算成功。原先是被排除的视频区域、没有静态主图时，后续实际出现的静态主图可作为变化证据。
- 仅支持实测过的 `thumbnail → thumbnailItem → IMG.thumbnailPic` 普通结构及唯一 `mainPicWrap → IMG.mainPic`。重复URL、多个选中标记、未知子控件、扫描截断或歧义仍停止或报告不支持。链接、禁用、inert、屏外或遮挡的缩略图禁止点击，但不据此丢弃已读取的当前主图数据；隐藏或不支持的图片区域不冒充有效主图。主图区域最多扫描60节点、深度6，已识别视频子树直接跳过，不读取其媒体地址。
- 回包丢失或进程中断不补点。读取故障、暂停或新一次执行会打断连续确认，旧候选不能与恢复后的观察拼成两次一致。首次有效读取太迟、剩余预算不足以完成两次后确认时不再选图。
- 沿用原任务每操作最多2次、平台最多5次故障重试和5／15秒等待档位，总等待预算120秒；不另加一套恢复额度。验证、登录和连接按通用[任务规则](tasks.md)暂停。`MAIN_IMAGE_UNCONFIRMED` 表示预算内未确认，不能自动重放。
- 开始读取后若重绑到新标签，`MAIN_IMAGE_TAB_CHANGED` 停止；旧标签的选择证据不能转给新标签。恢复原标签且身份仍匹配时可按原连接暂停流程继续。保持同一状态目录和计数。

结果保留最后处理的图片选择，不额外点击恢复原缩略图。读取主图不自动关闭用户或其他任务留下的面板；评价任务自身的条件收尾见[评价文字采样](review-text-sampling.md#面板状态与收尾边界)。

旧主图子格式1继续按原无遮挡及确认规则校验、恢复和回读，既有结果及检查点不升级、不补字段。格式变化不授权恢复已停止任务，也不能通过新建格式2任务刷新原批次预算。

## 交付字段

成功结果位于 `operations[0].result`，图片在 `samples[]`。中途暂停或停止时，已确认图片位于 `operations[0].partial_main_images`，未确认图片不混入成功样本。

新任务结果的 `schema_version: 2`、`source: loaded_main_image_dom` 表示已加载DOM数据，不能据此称当前无遮挡；旧格式1的 `visible_main_image_dom` 原样保留。

格式2未完成报告还返回 `operations[0].unconfirmed_main_image_observations`，最多当前未完成步骤的最后一份有效观察。`snapshot.image` 是当时实际读到的当前主图，可能不属于 `requested_thumbnail_url`；`association.requested_image_confirmed` 固定false，SKU为null／false。`observation_is_latest_read` 区分后续失败之前的旧观察，`original_tab_matches` 区分换标签。没有有效观察则数组为空。此字段供调用方分析，不用于跨故障凑两次确认，也不能直接作为 `image-export --region main` 的成功来源。

| 字段 | 含义 |
| --- | --- |
| `product_id`、`url` | 已核对的商品身份 |
| `samples[].thumbnail_url` | 请求并在当前页精确匹配的缩略图地址 |
| `samples[].image` | 主图元素实际URL、自然／显示尺寸、loaded及uncovered标记 |
| `samples[].observed_at`、`observations` | 两次确认的原页面时间；回读不改成当前时间 |
| `samples[].association` | 选中标记、两次一致、初始是否选中、动作意图后主图URL是否变化；SKU仍null／false |
| `samples[].action` | 是否预留动作、明确回执或安全错误码；不明回执不等于未点击 |
| `coverage`、`limits` | 请求／返回数量与上限；全图集、已下载、已识图、原始分辨率、视频读取均为false |

这里验证的是页面选中状态与显示主图的有限观察关系，不证明画面中所有型号属于选中SKU，不保证最高分辨率或链接长期有效。

主图结果只给实际主图链接。2026-10-28 起 Skill 不再下载图片（用户决定）：只交付图片链接，调用方需要文件或看图时自己按链接取得。
