## 使用

先查 `tabs`，复用或绑定准确商品页。调用方已有分类清单时，用精确名称编写 JSON 数组；名称未知时 `[null]` 只取当前选中分类，同时返回本次分类清单，不猜测平台分类。

```sh
node scripts/shopping.mjs task-start --task review-text --bindings mouse --review-categories examples/review-categories-current.json
node scripts/shopping.mjs task-run --task review-text
node scripts/shopping.mjs task-status --task review-text
```

[当前分类计划](../examples/review-categories-current.json)为 `[null]`；[鼠标两类计划](../examples/review-categories-mouse.json)为 `["全部","追评"]`，名称来自该样本，不是平台通用枚举。先确认实际控件。新批次需要明确范围，不能换任务名或状态目录绕过失败；开发仍使用 `.runtime/verification-bindings`。

## 自动打开与限次恢复

正常入口可唯一识别时，流程会自动打开面板，不要求用户每次手动打开。程序同时核对商品、正常预览区、准确的“查看全部评价”文字、节点类型和禁用／隐藏状态；先保存打开意图，再滚动一次到入口，做位置与遮挡检查，最多点击一次。已显示的面板不点击。打开回包只代表动作应答，后读必须确认实际评价内容进入视口；仅 Drawer 外壳在屏内不算成功。

每批文字采样共用12次读取预留，最多1次面板打开意图（含至多一次定位滚动）、每个请求分类最多1次切换意图。面板未确认最多3次检查，分类最多3次后检查；连续读取、动作后的观察至少等待1.5秒。动作先落盘，丢失应答或进程中断后只观察、不补点；中断／验证读取会打断连续确认，旧候选不跨故障使用。新建任务另有最多3次收尾状态读取及一次关闭意图，具体条件见下节。

重试与暂停仍遵守[共有任务规则](tasks.md)：普通临时故障最多2次重试、5／15秒等待；登录和验证码等用户处理、频控暂停；结构／未知遮挡／未知动作应答错误停止，不换任务重试。无法唯一识别正常入口时返回 `REVIEW_PANEL_REQUIRED` 或 `REVIEW_DRAWER_NOT_VISIBLE`；动作已经预留后不会再开一次。明确的门禁才要求用户登录或完成验证，不能把未知结构问题笼统称为平台风控。

## 面板状态与收尾边界

新建文字任务已接入 `panel_lifecycle`，记录初始状态、打开回执和后读确认。只在初始关闭、打开回执明确clicked:true、后读已确认展开、仍是原标签时，才在全部请求文字采样成功后自动恢复。初始已开、归属不明或重新绑定其他标签时不自动关闭。采样中途失败不在异常清理里继续操作页面。主图读取不调用评价关闭。

文字采样仍最多12次读取；新任务另有最多3次收尾元信息读取及1次关闭意图，总读取最多15次。先观察当前面板：已关闭则零关闭动作；仍打开才正常关闭一次，再两次连续确认关闭。所有意图先落盘、间隔至少1.5秒；剩余读取不足以确认时不再关闭。回包不明、中断或验证不补点、不新建任务；读取失败打断连续确认，恢复共用原任务的限次重试。收尾超限返回 `REVIEW_PANEL_CLEANUP_UNCONFIRMED`，已确认文字仍通过 `partial_category_samples` 交付。

任务报告和成功结果的 `panel_lifecycle` 返回 initial_state、open_acknowledgement、open_confirmed、status、observations、action_reserved、close_acknowledgement、acknowledgement_error、last_observation、last_read_error、closed_checks及固定limits。status包括preserved_initial／preserved_uncertain／preserved_changed_tab／already_closed／closed_confirmed；pending表示尚未完成收尾。报告的total_dom_observations_reserved合计文字与收尾读取，旧dom_observations_reserved含义仍只限文字采样。closed_confirmed表示观察到关闭状态，点击回包及是否由本方造成关闭仍分别看回执。旧检查点无该字段就不补写，旧成功任务不会重新关闭面板。

手机样本前轮由本方打开后遗留面板的问题已在原研究收据内恢复：生产关闭一次、两次确认关闭。当时新任务从初始观察、打开、采样到自动收尾的全链路仅离线集成验收；后续2026-10-03实页正例见上方最新补充。不重新打开评价制造测试条件。402项正式测试是当时双版本基线，详见实现与当时实页边界。

## 分类及文字证据

- 分类清单最多20项，保留页面原名称、数量展示文字、选中／禁用／视口状态和局部位置；数量如 `100+` 不转成精确总量，位置不是平台分类 ID。不假设好／中／差评，不以模型情感判断替换平台分类。
- 当前分类需要两次一致的文字观察。切换分类还必须确认目标选中、排序文字未变、文字列表相对切换前变化，随后连续两次一致；仅按钮选中或列表不变不能确认归属。控件变化、未加载或列表确实重叠而相同，也可能导致保守停止。
- 新集合子格式4按页面展示顺序保留前10个已加载主评位置。少于10条按实际返回，空正文保留 `text_observed: false`，不向后补到10条有文字评价；不翻页、不改排序，不称为“最新十条”或随机样本。
- 主评保留 `body`、购买日期／规格原文及可确定的拆分；每主评最多2条追评，每主评／追评最多2条商家回复，归属由同一 DOM 容器证明，省略数保留。
- 文字模式追评保留 `raw`、`interval_text`，不限定必须为“数字天后追评”。只有间隔字段确为原文前缀时才拆出 `body`；无法分割时 `body`、`text_observed` 为 `null`，原文保留供调用方使用。旧格式的校验和结果不改写。字数仍有限制，保留可能截断标志。
- 结果 `samples` 按分类交付，`association.category_ui_verified` 只表示界面与文字连续观察通过；`filter_algorithm_verified: false`。分类可能重叠，不凭重复文字去重，`review_id`、`unique_review_count` 为 `null`，不把各类数量相加称独立总量。
- `media_read: false`、`excluded: ['review_images','review_videos']` 表示主动排除媒体，不是采集失败。不会访问评价图片 URL、头像或用户主页。

完整结果的文字位于 `operations[0].result.samples[i].reviews`。中途停止时 `result` 为 null，已确认文字位于 `operations[0].partial_category_samples[i].snapshot.reviews`；两种字段路径不同。未确认分类不返回为成功样本，检查点保留动作意图、切换前基线和计数。不能将按钮选中或未通过校验的后读冒充确认结果。

## 未确认观察的交付

新建文字任务额外保存 `category_read.observation_delivery` 子格式1。未完成任务的报告增加 `operations[0].unconfirmed_category_observations`，只包含当前未确认步骤最后一次通过结构校验的观察，最多一份；它独立于已确认的 `partial_category_samples`，不授权更多读取或降低确认条件。

| 字段 | 含义 |
| --- | --- |
| `requested_category` | 本步请求的分类；`[null]` 在首次观察后固定为起始分类 |
| `selected_category_observed` | 该次读取时页面实际选中的分类，不保证文字属于它 |
| `snapshot.reviews` | 实际文字、追评／回复、覆盖和原 `observed_at`；最多前10个主评位置 |
| `read_index` / `phase` | 原读取计数及阶段：initial、after_switch或confirmation；序号不是平台ID |
| `association.status` | 固定 unverified；category_ui_verified、filter_algorithm_verified均为false |
| `association.reasons` | 未确认原因列表，见下方 |
| `observation_is_latest_read` | 是否来自最近一次读取；false表示后续读取没有产生可交付快照 |
| `latest_read` | 最近读取的原计数、阶段、结果状态和安全错误码；reserved也可能表示进程中断后结果未知 |

原因包括 `requested_category_not_selected`（目标分类未选中）、`sort_changed`（排序变化）、`text_unchanged_after_switch`（切换后文字未变）、`no_post_switch_observation`（尚无切换后的有效观察）和 `consecutive_confirmation_not_completed`（未完成连续确认）。这些字段描述读取证据，不推断平台风控或筛选算法。

加载中、验证失败或进程中断不会把旧文字改成新观察；旧快照及其时间可以保留，但连续确认候选仍清除，恢复后必须重新连续确认。成功确认后清除本步未确认快照。数组为空只表示新格式没有可交付的未确认文字，不表示页面没有评价。

旧检查点没有 observation_delivery时原样回读，不新增字段、不回填丢失观察，也不恢复其预算。普通淘宝原停止任务仍为旧格式；私有离线回放产物展示新交付，不改写正式历史结果。已有记录没有证明评价列表与选中分类的直接绑定；本次仅完善交付，文字相同仍不能确认切换，不新增猜测的DOM属性适配。376项完整测试在Node22／24通过，见离线实现与验收。
