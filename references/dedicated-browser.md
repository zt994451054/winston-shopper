# 旧浏览器通道与已保存结果

正式通道已改为 Playwright 扩展和常驻本机服务。旧 bb-browser 和通过远程调试启动专用 Chrome 的路径不再提供，也没有自动回退。新的安装与启动步骤见[环境准备](setup.md)。

要与日常浏览分开，可用 `setup --open-store --new-profile` 让 Chrome 新建一个专用资料，在其中装 Playwright 扩展；不要另开远程调试浏览器。此前专用 Chrome 在淘宝验证中无法正常使用，项目不隐藏自动化标记或绕过验证。

## 旧任务如何处理

- 保留原状态目录、检查点、观察时间、结果和预算，不改端点、协议名或任务字段来接上新服务。
- 用原任务的 `task-status` 回读，已有结果可用 `report-export` 导出；这些操作不连接浏览器。
- 已完成任务继续返回原缓存，不刷新数据。旧专用 Chrome 的未完成任务会返回 `LEGACY_BROWSER_TASK`，不连接或迁移页面。
- 旧 bb-browser 的未完成任务也不自动迁入 Playwright。切换前先清点；原端点遇到历史服务时会拒绝页面操作，不能据此改写检查点。
- 用户明确决定结束旧轮次时才用 `task-end`，它只在本地保留结果和计数并记为结束，不解除平台限制或刷新额度。

旧浏览器的启动、状态查询和任务迁入命令已删除。不要用旧文档里的启动参数尝试恢复；开发仓库的历史记录仅供追溯。
