# 规格清单与对应图片

2026-10-03新增同类正常样本：女款短袖1040479270864取得5颜色＋6尺码名称、5个独立1440×1440图片链接，名称1读／图片同批1读，总2/18、每颜色1/3次；支持图片缺项0，6尺码未见支持图片容器。没有切规格、加载滚动、重试或下载，SKU直接绑定仍未知，见[JSON](../examples/data/random-shirt-specification-collection-v3.json)与实测。此前两个成功样本及旧失败保留，新增正例不提升全平台覆盖率。

目标是取得请求商品的全部规格名称及对应图片。新任务先单独读取名称清单，再读取图片；每个已定位带图选项最多3次图片观察（首次＋最多2次补查）。每次最多5项只是分批方式，不是最多读取5个规格。规格选项不是平台SKU组合，不枚举笛卡尔积，也不用位置或属性值代替SKU ID。

此处预算只用于规格采集。详情正文、详情图列表、顶部图集、主图、评价及图片文件导出各有自己的任务与预算，不合并到规格图片的次数中；不同任务仍共用平台停止与互斥保护，不能换模式绕过故障。

## 新任务用法

```sh
node scripts/shopping.mjs task-start --task <请求任务名> --bindings <一个商品绑定> --specification-images --state-dir <原状态目录>
node scripts/shopping.mjs task-run --task <原任务名> --state-dir <原状态目录>
node scripts/shopping.mjs task-status --task <原任务名> --state-dir <原状态目录>
```

新建 `specification_collection.schema_version:3`。一次task-run自动执行名称清单、全部未处理图片、有限缺图补查；相邻读取至少间隔1.5秒，不逐批要求确认。只绑定一个商品，与详情、评价、服务、主图、图集和规格切换模式互斥。开发继续使用 `.runtime/verification-bindings`；页面访问前检查连接及tabs，不重放原停止任务或用新任务补额度。

## 名称、图片与总保护上限

| 范围 | 新格式3规则 |
| --- | --- |
| 名称清单 | 第一步只读组名、选项名称、位置及图片容器数量，不读IMG地址或尺寸；有效清单取得后不再重建名称快照 |
| 名称读取失败 | 最多3次清单读取预留，原故障重试与人工暂停仍先约束；不扣任何选项的图片次数 |
| 每个带图选项 | 最多3次图片读取预留，首次、补查、滚动保护、后读以及失败／中断均计入；正常链接取得后即停止该项 |
| 普通分批 | 最多5项，先读所有未处理项，再补查缺项；不同项共享URL时仍各自保留关联 |
| 按需滚动 | 每个选项最多1次意图，保护和后读各占该项1次图片预留；后读只检查这一项，不扣其他缺项次数 |
| 总内容读取保护 | 取得清单后按 `3 + 3 × N` 固定，N为已扫描到有支持图片容器的选项数；取得清单前仅开放3次名称读取 |
| 故障恢复 | 原每操作最多2次自动重试，跨全部批次共享，等待5秒／15秒；平台恢复和等待预算不变 |

总保护覆盖名称读取以及最坏情况下逐项检查的图片预算，实际分批通常远少于它；不会因为统一的10次上限让后面选项失去机会。N为0时只交付名称，不发出图片读取。总上限是保护值，不是要求用满，也不赋予绕过暂停的权限。

例如39个带图颜色＋8个纯文字尺码：先一次保存47个名称；正常图片首次读取分8批完成，共9次内容读取。若39项一直是异常小图，满足加载保护条件时每项至多再有一次保护和一次后读，总计最多87次实际内容读取；总保护值为120。每个颜色仍最多3次，8个尺码不占图片读取次数。这是算法示例，不是新的实页结果。

名称目标是读全，目前支持的结构扫描仍有最多8组、每组100项的保护。超过范围、隐藏或尚未进入受支持结构的内容不能保证读全；已知省略数必须交付，`scanned_inventory_complete:false`，不能称全量完成。该结构限制与图片次数分开。后续每次图片读取先核对整个已扫描清单，变化时在读取新URL前停止，不拼接不同结构的结果。

登录、验证码、连接或频控沿原task-resume流程暂停；验证码不自动重试。商品身份、来源归属或结构异常停止，保留已取得名称和图片。图片预算不是新的故障恢复额度，不能改名、换目录、换浏览器或改检查点继续。

支持来源内图片全部取得且名称扫描无截断时任务为complete，仅代表限定采集流程完成。名称、图片次数或结构上限到达仍有缺项时为stopped、SPECIFICATION_IMAGES_INCOMPLETE；故障停止保留原错误及状态。停止后的task-run只回缓存。

## 数据来源与按需加载

读取唯一支持的skuWrapper、skuItem和valueItem；所有已扫描文字都返回，含没有支持图片容器的选项。图片只取同组选项的唯一valueItemImgWrap内唯一IMG的实际currentSrc／src、加载标记和自然尺寸；隐藏祖先及已识别视频区域排除。无容器表示本方法没有识别来源，不认定商家无图。

正常采集不点击规格、下载图片、探测私有接口／隐藏应用状态、猜测URL或处理营销弹窗。只有所有图片项已完成首次尝试、名称扫描未截断、某项已确认唯一IMG为已加载小图（任一边≤2）、未预留过滚动且余下两次图片读取可用时，才安排该项加载保护。保护先落盘，再核对商品、清单、选项归属、原URL和尺寸；来源变化或已在可见区域就跳过滚动。仅同源仍小且在视口／祖先裁剪区外时执行一次普通scrollIntoView。

保护中的图片和几何是动作前数据，不证明图片已经加载。原节奏等待后只读该项；如果保护已发现正常图，就不为固定步骤追加后读。已选中标记冲突、身份／结构异常或阻挡动作的未知对话框均停止，不自行处理弹窗。不切规格，也不滚回。

动作回包丢失或进程中断仍占该项次数与滚动意图；允许恢复后只读，不重复滚动同一项。一个规格的补查失败不刷新另一个规格的次数，平台暂停仍中断整项任务。

## 交付字段

未完成及完成后都有 `operations[0].image_collection`；完成时result相同。来源为bounded_specification_collection，新结果版本3，旧结果不回填。

| 字段 | 含义 |
| --- | --- |
| inventory／inventory_observed_at | 首份有效的已扫描名称清单、容器数与当时观察时间 |
| options[] | 每个选项的组名、名称、原位置、图片预留次数、状态与已取得图片 |
| options[].observations[] | 原读取序号、时间、选中／禁用标记、来源和尺寸，保留早期小图；加载保护另标before_scroll／read_only |
| missing_images[] | 有支持容器但图片未取得的项，包含原因与已用次数 |
| unsupported_image_options[] | 未见支持图片容器的项，不等于商家无图 |
| collection.inventory_reads_reserved | 名称清单读取预留次数；不计入每个选项的attempts |
| collection.image_reads_reserved | 图片内容读取预留次数；一批可同时占最多5个选项各1次 |
| collection.content_reads_reserved | 上述两类预留之和，失败／中断也保留 |
| collection.budget_basis | 图片选项数量、计算公式、finalized；清单未取得时N为null且false |
| collection.limits | 总保护3＋3N、名称3次、每图3次、每普通批最多5项、滚动总N次且每项最多1次 |
| collection.loading_actions[] | 滚动意图、预期来源、真实回执与后读预留；unconfirmed不表示未派发，after_read不表示读取成功 |
| collection.observations_returned | 返回有效观察的次数，含名称读取，不等于图片数 |
| collection.stop_reason | 覆盖完成、名称／内容／单项读取或结构上限；访问故障另见任务状态与error |
| collection.next_read_available | 内容预算是否还有候选，不授权绕过停止或验证 |
| coverage | 已扫描名称／图片计数、未读和缺项、已知结构省略；不保证全平台、原图、语义或SKU覆盖 |

loaded_image_link表示实际IMG已加载、URL合规且宽高均大于2，不证明画面内容、原图分辨率或商家真实性。tiny_image_unresolved保留小图地址但不计入正常尺寸链接；这不是对所有占位图的识别保证。其他状态包含image_not_loaded、not_read、no_supported_image_container、image_element_not_observed、ambiguous_image_regions、ambiguous_image_elements与unsupported_image_url。

DOM唯一关联仅令option_binding_verified成立；`sku_id:null`、SKU／价格绑定false不变。不读取组合价格，不把优惠展示价当实付；不同次观察保留各自时间，cross_read_image_state_verified:false。完成的规格集合现可按[图片导出](image-reading.md)用 `--region specification` 导出正常尺寸链接；position为result.options数组下标加一，图片下载与页面读取各自计数。原短袖第1／26／36项三图下载及缓存已通过，其他36项没有下载。
