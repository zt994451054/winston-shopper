# 商品服务说明与有限展开

2026-10-03同一随机女款短袖的正式服务任务取得5条一级说明，记录1次展开意图、2/8内容读、回包错误null。更多／查看未点击，完整条款和资格仍false；没有独立持久clicked回执，不能用预留数冒充点击次数。见[完整结果](../examples/data/random-shirt-services-20261003.json)与实测记录。

需要读取服务条件时，使用明确的服务任务；默认 `--details` 仍只读当前已加载区域。

```sh
node scripts/shopping.mjs task-start --task product-services --bindings phone,shirt --services --state-dir <原目录>
node scripts/shopping.mjs task-run --task product-services --state-dir <原目录>
```

`--services` 与 `--bindings` 同用，最多 10 件，按商品 ID 去重；不能同时指定 `--details`、`--reviews`、`--plan` 或 `--search`。任务类型是 `product_services`，结果包含基础商品快照、详情和 `service_evidence`，不是 SKU 或权益认证。

## 动作与恢复

1. 在已保存目标上读取详情，先查 tabs；本次连接清单缺失原保存编号时，仅核对精确保存 ID 的地址，同商品才继续。
2. 已观察到服务浮层时直接返回，零点击。入口标记已展开但浮层尚未取得时只等待观察。
3. 确实需要展开时，先将唯一动作预留和有序服务标签落盘，再核对商品、标签、唯一入口、禁用与页面状态。若用户已在两次观察之间打开面板，则跳过点击，避免关闭它。
4. 动作后至少等待 1500 ms；每商品最多 8 次读取预留、3 次未确认检查、1 次动作预留。暂停／中断不退还计数，已保存动作永不重发。
5. 工具超时或连接传输失败、且不能确定动作是否发生时，记录回包错误并只读后观察。验证码、频控、目标问题和结构／协议异常保持各自暂停或停止；明确未派发的失败也保留服务动作预留。

普通读取失败继续使用原任务的两次自动重试、5／15 秒等待和平台累计预算，见[任务与恢复](tasks.md)。动作后的 1500 ms 属于正常观察节奏，不是故障恢复预算。完成任务再次执行只回读缓存，不重新访问商品。

`service_evidence.status: panel_observed` 只表示得到符合关联规则的浮层内容。`actions_reserved` 不是成功点击数：动作前失败、回包不明或用户已自行展开时都可能已经预留。`observations_reserved` 包含失败预留，`acknowledgement_error` 保留不明或失败回包；不能凭任务 complete 抹掉它。

## 内容与边界

服务说明在 `details.services.terms` 中，要求唯一展开入口、唯一支持浮层和有序标签一致。保留正文条件、排除项、截断／裁剪及二级入口，具体格式见[商品结果说明](products.md)。完整条款及适用资格始终未验证。

当前正式任务只展开一级商品服务面板，不点击“更多／查看”，不访问订单详情，也不提交售后。二级入口的存在、动作派发及完整规则取得是不同事实；没有读到正文时，不认定该入口无效或平台没有规则。

图片导出继续使用原 `product_details` 来源任务和原收据；新的服务任务不是同商品图片的新额度来源。默认详情行为和旧缓存不变。
